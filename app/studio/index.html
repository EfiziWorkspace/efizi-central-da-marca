Skills da marca

As skills que produzem na cara da Efizi, pra você usar no seu Claude Code. Baixe só a que precisar.

Como instalar

  1. Baixe o .zip da skill que quiser (abaixo).
  2. Descompacte e copie a pasta para ~/.claude/skills/.
  3. Reinicie o Claude Code. A skill aparece na lista; use pedindo naturalmente ou com /nome-da-skill.
Pré-requisitos: Claude Code instalado. As skills marcadas com o ponto laranja precisam de conta no Higgsfield (geração de imagem). Algumas assumem o repo da marca (fontes/logos) — se precisar, fale com o Guilherme.
